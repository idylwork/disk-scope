# Disk Scope

ディスク占有量の大きいフォルダやファイルを高速に可視化し、効率よく空き容量を増やすための macOS アプリケーションです。

## 使い方

1. **スキャン開始** からフォルダを選びます。
   初回はフルディスクアクセス許諾が表示されます。書類やデスクトップなどをまとめて読む場合はシステム設定で Disk Scope のフルディスクアクセスをオンにします。
2. スキャンが終了すると、円グラフでフォルダ内のファイルサイズ比率が表示されます。円グラフのスライスをクリックすると右側に詳細が出ます。フォルダをダブルクリックするとその階層に入り、中心をクリックすると一つ上に戻ります。
3. 詳細ではサイズと内訳を確認できます。走査ルート以外は名前をクリックして改名でき、**ゴミ箱に入れる** でのゴミ箱へ移せます。

## 開発

初回は依存関係を入れます。

```bash
npm install
```

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | デスクトップアプリを開発モードで起動する |
| `npm run build` | 配布用アプリをビルドする |
| `npm run dev:web` | フロントエンド（Vite）だけを起動する。ネイティブ機能は使えない |
| `npm run build:web` | フロントエンドを型チェックして本番ビルドする |
| `npm run preview:web` | フロントエンドの本番ビルドをローカルで確認する |
| `npm run tauri` | Tauri CLI のエントリ。後ろにサブコマンドを付ける |
